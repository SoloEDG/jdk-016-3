# 折间 ORI

三维折纸工作室。除了预设折纸，还可以在平面展开图上自己绘制折痕：

- 点击「绘制自定义折痕」进入设计模式，在展开图上点击两点成折；线段可从纸边连到已有折痕，交点自动分割纸面，新纸面继承双面材质与局部位置。
- 绘制即时预览；「完成并生成步骤」把新折痕追加进折叠步骤序列，既有步骤形态保持不变；「放弃本次绘制」整体回滚。
- 多条折痕形成闭环时不会删边造假：可独立转动的折痕与受闭环约束的折痕会区分标注，折叠不可行时冲突区域标红提示，作品不受损。
- 超短线段与几乎重合的交点会被吸附合并，不会产生细碎闪烁纸面。

## 本地启动

```sh
npm install
npm run dev
```

## 检查与构建

```sh
npm run typecheck
npm run build
```

## Docker

```sh
docker compose up --build
```

访问 http://localhost:18116。
